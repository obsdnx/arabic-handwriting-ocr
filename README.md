# Optimising LightWeight CNNs for Arabic Handwriting Recognition


This repository contains the source files for a final-year academic report/dissertation focusing on Arabic Handwriting Recognition (AHR).

The project investigates and optimizes the performance of Lightweight Convolutional Neural Networks (CNNs) for accurately recognizing handwritten Arabic script, a challenging task due to the cursive nature and complex character shapes of the language.

Key Focus Areas:Model Optimization: Exploration and application of techniques to enhance the efficiency and accuracy of CNN models (such as MobileNet, ShuffleNet, or custom lightweight architectures) for deployment in resource-constrained environments.Arabic Script Analysis: Addressing the unique complexities of the Arabic writing system, including diacritics, ligatures, and contextual variations in character forms.Methodology and Implementation: Detailed documentation of the data preprocessing, model architecture design, training regimen, and the use of specific dataset(s) for the AHR task.Evaluation: Comprehensive analysis of the optimized model's performance, contrasting the results against baseline and state-of-the-art AHR systems.Project Deliverables (Contained in this Repository):$\LaTeX$ Source Files: The complete $\LaTeX$ source code used to generate the final report.Bibliography: The sources.bib file containing all references used in the research.Full Report (PDF): The compiled PDF of the final academic work, including the abstract, methodology, results, and conclusions.
